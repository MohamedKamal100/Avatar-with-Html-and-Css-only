# 🌐 Responsive Landing Page

A clean and modern responsive landing page built with HTML & CSS.

## 🚀 Demo

🔗 [Click Here](https://mohamedkamal100.github.io/Avatar-with-Html-and-Css-only/)

## ✨ Features

* Responsive design (mobile, tablet, desktop)
* Gradient background with image overlay
* Simple navigation with hover effects
* Clean UI and typography

## 🛠️ Tech Stack

* HTML5
* CSS3 (Flexbox + Media Queries)
* Google Fonts

## 📂 Structure

```
index.html
style.css
Images/avatar.jpg
```

## ▶️ Run Locally

Just open `index.html` in your browser.
